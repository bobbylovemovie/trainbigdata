# Lab 6 -- Impala (เลิกใช้ / ไม่บังคับ)

**ภาษาไทย** | [English](README.md)

## ทำไมถึงไม่มี lab นี้ให้ลงมือทำจริง

Impala **ไม่ได้ติดตั้งอยู่ใน sandbox นี้** เหตุผล:

Impala เดิมผูกติดกับการแพ็กเกจของ Cloudera ค่อนข้างแน่น และต้องเพิ่ม
daemon ระดับ JVM อีกชุด (catalogd, statestored, impalad) พร้อมระบบแคช
metadata ของตัวเอง ซึ่งเป็นภาระที่หนักเกินไปสำหรับ sandbox แบบ
single-node ที่เน้นการเรียนรู้ ในขณะที่เป้าหมายการเรียนรู้เดิม ("SQL
แบบ interactive ที่เร็ว บนตารางเดียวกัน") ถูกครอบคลุมอยู่แล้วโดย
Hive/Beeline (lab 05) และ Spark SQL (lab 10)

## ถ้าอยากได้ตัวทดแทนในอนาคต

ถ้าต้องการ SQL engine แบบ interactive ที่เร็วบนตาราง Hive ในเฟสถัดไป
**Trino** (https://trino.io) คือตัวทดแทนสมัยใหม่ที่เหมาะสม -- เป็น
binary เดียวรันง่าย มี connector เชื่อมกับ Hive metastore ตัวเดียวกับที่
sandbox นี้ใช้อยู่แล้ว และไม่ผูกกับ vendor รายใดรายหนึ่ง ยังไม่ได้ทำใน
เฟสนี้เพื่อไม่ให้เพิ่ม query engine ตัวที่สองก่อนที่ stack หลักจะพิสูจน์
ตัวเองว่าใช้งานได้มั่นคงก่อน
