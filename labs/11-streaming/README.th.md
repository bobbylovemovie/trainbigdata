# Lab 11 -- Spark Streaming

**ภาษาไทย** | [English](README.md)

## เป้าหมายของ lab นี้

เรียนรู้การประมวลผลข้อมูลแบบ **streaming** (ข้อมูลไหลเข้ามาต่อเนื่อง
ไม่รู้จบ) ต่างจาก lab ก่อนหน้าทั้งหมดที่เป็น **batch** (ข้อมูลนิ่งอยู่
ในไฟล์แล้วค่อยประมวลผลทีเดียว)

> ตัวอย่างเดิมใช้ API แบบ DStream (เก็บไว้อ้างอิงที่
> `legacy/Spark/StreamingWordCount_dstream.py`) ซึ่ง Spark เองก็ประกาศ
> เลิกแนะนำให้ใช้แล้ว หันไปใช้ **Structured Streaming** แทน (API ใหม่ที่
> เขียนคล้าย Spark SQL/DataFrame ธรรมดา แค่ข้อมูลไหลเข้ามาเรื่อย ๆ)

## แนวคิด

```text
คุณพิมพ์ข้อความผ่าน terminal (nc)
        |
        v  ส่งผ่าน socket
Spark Structured Streaming อ่านทีละ "micro-batch"
        |
        v
พิมพ์ผลนับคำที่อัปเดตล่าสุดออกทาง console
```

## ขั้นตอนที่ 1: เปิด terminal สองหน้าต่าง

เช่นเดียวกับ lab 7 (Flume) lab นี้ต้องใช้ 2 terminal พร้อมกัน ทั้งสอง
หน้าต่างต้องเข้า container แยกกัน

**Terminal ที่ 1 -- เปิดตัวรับข้อมูล (netcat):**

```bash
docker compose exec bigdata bash
nc -lk 9999
```

`-l` แปลว่าเปิดโหมด listen (รอรับการเชื่อมต่อ) `-k` แปลว่าเชื่อมต่อใหม่
ได้เรื่อย ๆ ไม่ปิดตัวเองหลังการเชื่อมต่อแรกจบ **ปล่อยหน้าต่างนี้ทิ้งไว้
รอพิมพ์ข้อความในขั้นตอนที่ 3**

## ขั้นตอนที่ 2: เปิดโปรแกรม Spark Streaming

**Terminal ที่ 2 -- อีกหน้าต่างแยกต่างหาก:**

```bash
docker compose exec bigdata bash
spark-submit ~/labs/11-streaming/streaming_wordcount.py
```

โปรแกรมนี้จะเชื่อมต่อไปที่ `localhost:9999` (ที่ Terminal 1 เปิดรออยู่)
แล้วรอรับข้อความ จะยังไม่มีอะไรขึ้นจนกว่าจะพิมพ์อะไรบางอย่างใน Terminal 1

## ขั้นตอนที่ 3: พิมพ์ข้อความทดสอบ

กลับไปที่ **Terminal 1** พิมพ์ข้อความอะไรก็ได้แล้วกด Enter:

```text
hello world hello spark
```

สลับกลับมาดู **Terminal 2** จะเห็นตารางผลนับคำ (micro-batch) แสดงขึ้นมา
ประมาณนี้:

```text
-------------------------------------------
Batch: 1
-------------------------------------------
+-----+-----+
| word|count|
+-----+-----+
|hello|    2|
|world|    1|
|spark|    1|
+-----+-----+
```

พิมพ์ข้อความเพิ่มใน Terminal 1 อีกรอบ (เช่นพิมพ์คำว่า `hello` ซ้ำอีก)
แล้วดู Terminal 2 -- ตัวเลขจะ**สะสมเพิ่มขึ้น** ไม่ใช่เริ่มนับใหม่ทุกครั้ง
(เพราะโปรแกรมนี้ใช้ `outputMode("complete")` ซึ่งคำนวณผลรวมสะสมของ
ทุกข้อความที่เคยได้รับมาตั้งแต่ต้น)

## ขั้นตอนที่ 4: หยุดการทดสอบ

กด `Ctrl+C` ที่ **Terminal 2** เพื่อหยุดโปรแกรม Spark Streaming แล้ว
`Ctrl+C` ที่ **Terminal 1** เพื่อปิด `nc`

## อ่านโค้ดเพิ่มเติม

เปิดไฟล์ `streaming_wordcount.py` ในโฟลเดอร์นี้ดู จะเห็นว่าหน้าตาโค้ด
คล้าย Spark SQL ธรรมดามาก (lab 10) ต่างกันแค่:

- อ่านข้อมูลด้วย `spark.readStream` แทน `spark.read`
- เขียนผลลัพธ์ด้วย `.writeStream` แทน `.show()` ธรรมดา พร้อมระบุ
  `outputMode` (วิธีอัปเดตผลลัพธ์เมื่อมีข้อมูลใหม่เข้ามา)

## ถ้าเจอปัญหา

| อาการ | สาเหตุ/วิธีแก้ |
|---|---|
| Terminal 2 ไม่ขึ้นผลอะไรเลยหลังพิมพ์ใน Terminal 1 | เช็คว่าพิมพ์ใน Terminal ที่รัน `nc -lk 9999` จริง (ไม่ใช่หน้าต่างอื่น) และกด Enter หลังพิมพ์ทุกครั้ง |
| `spark-submit` ขึ้น error เชื่อมต่อ port 9999 ไม่ได้ | เปิด Terminal 1 (`nc -lk 9999`) ให้เสร็จ**ก่อน** แล้วค่อยสั่ง `spark-submit` ที่ Terminal 2 |
